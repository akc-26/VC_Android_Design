9. SHAPE AND SPACING SYSTEM
==================================================

Use a controlled shape language.

Suggested roles:

- Small controls: 10–12dp
- Compact cards: 14–16dp
- Standard cards: 18–20dp
- Hero surfaces: 24–28dp
- Bottom sheets: 28–32dp top corners
- Pills: full radius
- Avatars: circular

Use the semantic spacing system:

4 / 8 / 12 / 16 / 20 / 24 / 32 / 40

Primary page gutter:

16dp

Major section separation:

20–24dp

Control grouping:

8–12dp

Hero spacing:

24–32dp

Use these as design-system values, not isolated screen decisions.
